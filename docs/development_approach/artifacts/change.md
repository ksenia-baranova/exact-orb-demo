# Шаблон: change.md

Файл: `docs/project_management/changes/<change-id>/change.md`. Пишет Manager в задаче intake, правит в apply_decisions. Статус изменения во frontmatter пишет только оркестратор.

Правила:

- Каждый раздел — простым языком, без ID и SHA, кроме «Источников».
- Цель измерима: по ней в конце можно сказать «достигнута» или «нет».
- Тип refactor — только если поведение не меняется. Тогда в «Цели» метрика до и после, а в «Вне скоупа» — «внешний контракт и тесты публичного поведения не меняются».

## Заготовка

id: <CH-id>
status: INTAKE        # пишет оркестратор
