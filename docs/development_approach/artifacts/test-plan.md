# Шаблон: тест-план

Файл: `docs/project_management/changes/<change-id>/plans/test_plan.md`. Пишет Tester в задаче review (ALIGNMENT), дополняет и прогоняет в задаче test.

Тест-план — это список тестов, которые будут запущены, а не описание стратегии. Он же матрица покрытия: связь «требование → тесты» видна по полю req, и отдельной таблицы покрытия нет.

Правила:

- План пишется по требованиям до чтения кода и тестов Developer.
- Один тест — одно проверяемое поведение.
- Then говорит словами, что проверяем. Точные значения — только в «Ожидаемом результате», в одном месте.
- Ожидаемый результат берётся из требования или независимого источника и записывается до запуска. Копировать фактический вывод программы в ожидаемый нельзя.
- Каждая строка таблицы условий у Analyst — отдельный тест или строка в «Примерах».
- Автотест повторяет Given / When / Then комментариями дословно и помечен `@pytest.mark.req("<REQ>")`.

## Пример заполненного теста

Пример иллюстрирует формат, а не требования проекта.

```markdown
### T-03 Ошибка проверки без принятой карты показывает форму
req: REQ-UI-03 строка 3
вид: негативный
уровень: интеграционный
риск: средний
автотест: tests/acceptance/test_ui_response.py::test_validation_error_without_chart_shows_form
статус: FAIL @ 5fdc477 → BUG-004

Given принятой карты в сессии нет
When сервер отвечает ошибкой проверки «время не указано»
Then пользователь видит форму с сообщением под полем времени
And колесо не показывается

Ожидаемый результат: форма открыта; под полем «Время» текст «Укажите время рождения»; элементов колеса на странице 0.
Источник ожидаемого: REQ-UI-03 строка 3; текст сообщения — REQ-UI-09.
```

Автотест к нему:

```python
@pytest.mark.req("REQ-UI-03")
def test_validation_error_without_chart_shows_form(page, server):
    # Given принятой карты в сессии нет
    server.reset_session()

    # When сервер отвечает ошибкой проверки «время не указано»
    server.reply_validation_error(field="time")
    page.submit_form()

    # Then пользователь видит форму с сообщением под полем времени
    assert page.form_is_visible()
    assert page.field_error("time") == "Укажите время рождения"
    # And колесо не показывается
    assert page.wheel_elements_count() == 0
```
