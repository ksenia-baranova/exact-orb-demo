## 2. CSS reference, bounds и положительные/отрицательные controls

Одна SVG user unit = один CSS px; `width=W`, `viewBox=0 0 W H`, никакого уменьшения всего SVG через transform. CSS origin — левый верхний угол самого SVG, без page padding/header. Reference центра C и радиуса задаётся текущей композицией. Для natal origin=опубликованная ASC longitude, для cosmogram origin=0; `x=Cx-r*cos((longitude-origin)*π/180)`, `y=Cy+r*sin(...)`. В C0/перемещении/return A означает фактическую default позицию producer; идеальный reference A* используется для оценки ошибки координат. Реальная точка — округление producer до1/64px; независимая ошибка — Euclidean norm от **идеального** reference, максимум0,5 CSS px. Получено max0,010848716508144922px. Концы обычных аспектов используют истинные долготы в core, а не перемещённые подписи. Геометрический anchor ☌ — середина двух реальных endpoint-координат, без пересчёта aspect/type/orb.

Bounds компонента — измеренный нативный SVG `getBBox`, сверенный с CSS `getBoundingClientRect`/CTM; для point/☌ резервируется максимум selected contour0,75px с каждой стороны (stroke1,5). R, короткое имя в колонке, angle text — самостоятельные компоненты. Состав группы — union компонентов, без замены его описанной окружностью. Измеряем bbox-консервативную границу текста, не заявляем отдельный pixel-ink/raster certificate. Истинная отметка имеет radius1. Она рисуется **под** собственным несмещённым символом и остаётся видимой при выносе; поверх символа её рисовать нельзя. Фон подписи отделяет её от декоративных линий.

Для AABB `a,b`: `dx=max(a.left-b.right,b.left-a.right,0)`, аналогично dy; `gap=sqrt(dx²+dy²)`. Допустимо **gap≥2**, равенство включено. Независимый native verifier считает `dx²+dy²≥4` точными Fraction от binary64, без epsilon. Проверяются чужие foreground labels и чужие true-anchor squares; собственные части проверяются по их заданным offsets. Декоративные cusps/aspect strokes лежат под labels; чужой label не может скрывать истинный anchor. Выносная линия обходит чужие label bounds; label gap2 не превращается в требование2px между всеми аспектными хордами.

Clip — весь SVG rectangle[0,W]×[0,H]; все reserved text/contour bounds внутри, все visible leader strokes внутри. Зодиак — неподвижная область внешнего кольца; aux-кандидаты находятся внутри `R-24`, corners bbox входят в диск. Default point ring: `r=R-26-max(measured glyph/R corner reach)-2`, так подпись не заезжает на zodiac. Ни радиус, ни сторона/размеры колонки из старого preview не объявляются универсальным Owner-числом.

## 3. Колонка: trigger, группы, порядок, минимальность, resize

1. Сначала измерить glyph/R/angle/☌/sign при реальном шрифте. На default W-круге построить граф конфликтов. Вершины связаны при gap<2; label, перекрывающий чужую истинную отметку, тоже конфликтует. Числа градусов в trigger нет. Если point-конфликтов нет, колонка не резервируется: sparse и empty-cosmogram сохраняют весь круг.
2. Если конфликт есть, для **проверяемого технического варианта** резервируется одна левая колонка. Её ширина — max измеренных glyph+R+short name +8px; gutter12px, D=W-columnWidth-12. Затем default graph/C0 заново определяется в этой конечной системе координат, до перемещения меток. Изменение размера круга при композиции не является сдвигом отдельного point по долготе. Весь source DTO неизменен.
3. Колонка содержит только incident point-вершины окончательного C0; остальные point P=A и не имеют leader. Связные конфликтующие группы сохраняются как части одного упорядоченного списка, без удаления остальных points. Только point-метки получают short names/R в колонке. ☌ и angles не переводятся в неё автоматически.
4. Полный порядок — longitude ascending с разрезом после наибольшего пустого cyclic gap; на равных долготах нужен стабильный canonical-ID tie-break, независимый от locale. По колонке идёт соответствующая подпоследовательность. Exact coincident-longitude tie должен получить отдельный regression при реализации; текущая матрица проверяет0° seam/близкие, не все возможные точные совпадения.
5. X right-align к внутреннему краю колонки. Для bbox B_i и origins y_i обязательна `y_(i+1)-y_i ≥ bottom(B_i)-top(B_(i+1))+2`; нельзя заменять асимметричный bbox половиной высоты. Y выбирается isotonic L2 projection к default anchor-y с этими constraints; producer block precision1/64. H=max(D,Σheight+2(n-1)+16). При нехватке высоты блок растёт; шрифт и данные не сокращаются. В наблюдённом F3-max/W328: column95, wheel221, SVG H406 CSS px. Это actual примера, не фиксированное требование.
6. Минимальность внешней колонки — отсутствие выноса вне C0, минимальная необходимая высота при выбранном D/row order и сжатие строк относительно anchor-y. Независимый post-audit не находит улучшающего contiguous ±1/64px shift в29/29 клетках. **Это новая техническая постановка для column domain, не старый annular/chord-return PASS.** Геометрический глобальный optimum или минимальное число вершин во всех мыслимых раскладках не требуется/не доказан. Перенос этого определения — адресная дельта критериев, которую сверяют Analyst/Tester.
7. На resize controller сохраняет selection/five-all/draft, получает новую фактическую CSS width, отзывает старую drawing revision и пересчитывает только представление. Loading font также создаёт новую revision или допускает publish текущей lease; stale lease не устанавливается. Не вводить hysteresis/TTL/fixed angular threshold. Минимальный D176 в harness — исследовательский guard; при неподдержанном размере сохраняется конкретный layout failure, без автоматического скрытия/уменьшения glyphs.

## 5. Renderer boundary: конкретная рекомендация

ResultController единолично владеет live image host, accepted envelope/once cause/index/selection, HTML presenter и revision tokens. Renderer получает глубокую неизменяемую копию presentation snapshot, собственную connected measurement surface текущей revision и `publish(svg)`; live host/установленная копия ему не передаются. Оригинальная поверхность сохраняется до revoke, чтобы current font callback мог измерить и опубликовать повторно. При revoke она снимается; retained old DOM reference существует лишь как detached дерево.

Publish: проверить instance+revision+acceptance token → validate passive SVG → deep clone → **повторная проверка token после clone** → одна синхронная install transaction без await. Leaf сохраняет только исходное дерево; его поздние mutations не меняют копию. Установка запрещает активные/внешние узлы, on*, href/url, tabindex, positioning styles; для production нужен закрытый attr/value whitelist и запрет внешних ID references. Harness подтвердил закрытый tag set, event/style guards и безопасную обработку CSSOM overflow shorthand. Это дисциплина внутренних same-origin modules, не sandbox для недоверенного JavaScript.

На accepted B: **revoke A → remove old imagery → full index/once/reconcile и HTML/summary B → guarded synchronous dispose retired instance once → guarded draw B**. Dispose throw диагностируется, B остаётся; same instance/new revision не требует instance disposal. Factory/sync update/async rejection текущей lease дают локальный `svg_unavailable`, revoke failed lease и удаление только imagery; late rejection диагностирует retired revision. HTML/controller failure остаётся в существующем safe-read пути. Index/once policy/HTML и создание controller snapshot находятся вне leaf guard; production обязан отдельно закрепить fault partition тестом, включая неожиданную ошибку adapter, чтобы широкий catch не маскировал controller defect. Эти fault injections в изолированном harness не выполнены. Ни leaf fault, ни selection/resize не инициируют HTTP/build. Final close idempotent.

[28 controls/trace](evidence/column_full_composition_v1/run07-ports/boundary.json) проверяют: original-vs-copy mutation, stale publish до/после settlement, same-instance revision, sync/async/factory fault, revocation после rejection, dispose fault/order/idempotence, immutable snapshot, measurement lifetime, successful current late publish, reentrant clone revoke, запрещённый positioning style, настоящий SVG F1/F3-max, сохранение живой HTML-кнопки/focus и независимый alternate renderer после ошибок. Это isolated seam, не смонтированная production session/recovery/HTML реализация.
