Остальные строки доступны без запроса и без потери данных. Для пяти или меньшего числа строк лишняя кнопка скрыта.

Три раскрытия независимы. Automatic current сохраняет раскрытие планет; существующий однократный reset новой принятой карты по изменённым birth data сбрасывает его вместе с другими раскрытиями. Смена выбора планеты не сбрасывает раскрытие и не переносит focus. Режим выбранного аспекта показывает только всех его опубликованных participants (до двух points, включая точки за пределами первой пятёрки), скрывает кнопку раскрытия и при выходе возвращает прежнее состояние таблицы. Углы по-прежнему не выдумываются как planets.

Ограничение касается HTML-таблицы. Полный SVG-набор, source DTO, позиции, дома, aspect addressing/S1 и API не меняются.
