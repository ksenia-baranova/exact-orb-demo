## 2. Техническое решение и минимальный первый результат

**Направление выбрано Owner:** HTML native controls → один canonical selection/controller state → HTML и позднее пассивный SVG читают одно accepted состояние. SVG не выбирает point/aspect и не получает click/tap/Enter/Space, tabindex, Q44 или отдельную focus policy. Визуальная обратная связь point/пары/линии/☌ сохраняется. Прежние hit FAIL остаются историческими FAIL исключённой функции; visual gap/anchor/fonts/R/order/leaders/minimality не ослаблены.

**Первый implementation scope:** реальная state/HTML часть без зависимости от готовой геометрии — accepted-event identity, canonical index/selection, retained points/aspects/houses, five/all и planet-filter, S1 warnings и reconcile, редактор/сводка/live focus. Это компонентный этап разработки, **не готовая поставка всего M1-8** и не HTML-only fallback вместо колеса. Не добавлять фиктивный WheelPort, пустой renderer, ложный svg_unavailable, future exports или feature flag ради видимости завершения. SVG-реализация подключается отдельным work item после принятия её границы.

Минимальная организация: [session.mjs](../../../../../src/exact_orb/http_api/ui/session.mjs) остаётся accept-owner / владельцем HTTP и recovery; presentation controller внутри UI владеет selection/expansion и текущим accepted envelope, [facts.mjs](../../../../../src/exact_orb/http_api/ui/facts.mjs) — выводом фактов / keyed HTML; [main.mjs](../../../../../src/exact_orb/http_api/ui/main.mjs) — wiring формы, сводки, доступности controls. Не вводить сервисную прослойку. Отдельный внутренний модуль controller возможен только с фактическим использованием в этом этапе; не сохранять API на будущее. `readChartFacts` остаётся форматированием опубликованных значений без доменных пересчётов; canonical index строится из полного исходного DTO до его сокращения для отображения.

### Рекомендация для будущего passive renderer / DP-O-010

Упростить D005-предложение до **изолированного SVG root на каждую revision + guarded copy/install**: renderer работает только со своим detached/изолированным measurement root, не получает live host и mutable currentHost. Controller проверяет instance/revision прямо перед синхронной установкой **копии** SVG; исходный root не присоединяется как live imagery, поэтому retained reference старого renderer не пишет в установленную копию до/после settlement. Исходы factory/update sync throw/async rejection локальны: HTML новой принятой B уже опубликован, A удалена, dispose guard не блокирует B. Same-origin дисциплина не объявляется security sandbox.

Пассивному SVG не нужны перенос event handlers / native capabilities или сохранение active SVG node; HTML-controls сохраняются по ключу. Измерение шрифтов/root lifecycle/проверка копирования attrs и запрещённых interactive attributes — отдельные implementation checks. Generic value-frame writer из D005 остаётся альтернативой, **не автоматически выбранным новым объёмом**. R002 / владелец DP-O-010 проверяют достаточность и принимают необходимую границу. Новый ADR / нормативный перенос / код renderer / spike этим D006 не выполняются. Преимущество — меньше обязанностей adapter; количественная экономия без реализации не заявлена.

По geometry остаётся адресный следующий шаг после разрешения: bounds normal/selected без отменённого SVG-focus, пересчитать исходный C0, затем order-preserving placement с независимым directional-boundary certificate возврата. Удаление hit/focus не доказывает исчезновение10 visual failures или256 local-prefix witnesses D005. Нельзя просто принять прежнюю projection, уменьшить font/gap или повторить весь старый Q44 run. Новая конкретная модель/лимит назначаются отдельно по R002; geometry не задерживает допуск независимых HTML work items.
