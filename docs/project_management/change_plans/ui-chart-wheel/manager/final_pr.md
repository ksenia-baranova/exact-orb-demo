# feat(ui): пассивное колесо карты и выбор через таблицы

Тип передачи: подготовленный итоговый пакет; перед открытием ready PR заполнить
точные head/base SHA и подтвердить оставшиеся условия Manager §2.30.

После построения или восстановления карты страница показывает пассивное SVG,
сводку и доступные HTML-таблицы. Выбор планеты фильтрует её аспекты; выбор аспекта
показывает участников и опубликованные дома с явным возвратом. Все три таблицы
независимо раскрываются из первых пяти строк. Внутренние ряды планет сохраняют
source факты; локальная ошибка SVG оставляет HTML доступным.

Пакет включает реализацию, tests/evidence, 22 требования, 53 сценария,
8 текущих/3 архивных sequence diagrams и технический ADR. API/engine/числовой
контракт не меняются. Статус принятия ADR и адресной сверки переноса проверяются
по Manager, а не выводятся из наличия файлов.

Проверки реализации: независимый RetestedSHA9974195 — Chrome/Yandex1440/768/360,
6/6 cases,672/672 checks;229 UI,53 target Python,2959 pytest+1 legacy skip.
Текущий документальный проход:229 Node tests pass; воспроизводимые ссылки,
hashes/IDs/отсутствие source-копий и сохранность runtime — Manager checks.
Browser/HTTPS/full pytest/PlantUML render этим проходом не запускались.

Ограничения: DEBT-UI-002/003/004 OPEN; TEST-FIND-WHEEL-002/precision INDETERMINATE,
универсальная плотность/радиальная точность не сертифицированы. TEST-FIND-WHEEL-004
CLOSED по независимому ретесту. Долг опубликован отдельным registry PR:
URL / RegistrySHA должны быть внесены после его merge.

Main имеет историю ошибочного test merge/revert. План разрешения документальных
modify/delete пересечений — [main integration](main_integration_plan.md);
кодовых пересечений при проверенном MainBaseline нет. Перед merge проверить
актуальность базы, результат адресного T009 и применимость Owner-решения по ADR-0042 для текущего пассивного M1-8;
после merge зафиксировать MergeSHA и сверить значимый пакет.

Owner§2.31 разрешил только commit/push подготовленного пакета в change. Этот текст остаётся подготовкой; создание PR и merge не разрешены. Активное колесо — будущая фича вне текущего PR.
