## Подход

Отдельная страница условий — второе состояние существующего UI без перезагрузки документа: нативная ссылка под checkbox ведёт к секции условий, `main.mjs` переключает видимые области. Живые form/places/session/result и DOM полей сохраняются; snapshot не сериализуется и не восстанавливается из storage. Это сохраняет неполный ввод, place_id и строку времени при неизвестности без нового механизма persistence.

Переиспользуем `createBirthForm().acknowledge()`, `snapshot()`, существующий submit gate и HTTP/recovery. На открытии focus получает заголовок условий с `tabindex="-1"`; оба возврата раскрывают редактор и фокусируют ссылку условий в форме. Повторный возврат после закрытия страницы ничего не делает. Расчёт, HTTP DTO, сессия, кэш, колесо и юридическое согласие вне изменения.

Предусловие первого implement: штатный APPROVAL получен, конкретная редакция публикуемого текста утверждена Owner и доступна в inputs. `terms_draft.md` сейчас черновик; DP-A-01 утвердил только контакт. Это существующая зависимость, а не новый DP. Без утверждения нельзя подменять текст заглушкой или объявлять REQ-TERMS-06 выполненным.
