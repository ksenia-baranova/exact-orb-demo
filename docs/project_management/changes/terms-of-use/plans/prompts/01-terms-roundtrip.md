Проблема: пользователь видит отметку ознакомления, но не может прочитать условия из формы.
Что делаем: открываем утверждённые условия и возвращаем заполненную форму двумя согласованными способами.
Готово, когда: обе кнопки сохраняют введённое, согласие выбирает отметку, а расчёт начинается отдельным действием.
Не делаем: юридическое согласие, сохранение подтверждений, изменения расчёта, серверных данных и чата.

## Структура
Статическая секция условий — сосед `#birth-page` внутри прежнего main; нативная ссылка находится под checkbox вне его label, кнопки имеют type=button вне form. Существующие form/places/session/result и DOM не пересоздаются.
`main.mjs`: openTerms, returnFromTerms, renderPage и termsOpen; таблица TERMS_RETURN_ACTIONS хранит agree→выбрать, back→сохранить. Использовать form.acknowledge(), не второй checkbox-state. Заголовок получает focus на открытии, ссылка в видимом раскрытом редакторе — на возврате.
Новых журналов и бизнес-вызовов нет; HTTP/recovery и acceptance остаются у session.mjs. Разметка и CSS включают полный текст, переносы и доступные области; отдельный Markdown runtime не добавляется.

## Шаги
1. Подход тест → код: новый `tests/ui/terms.test.mjs` монтирует настоящий UI и leaf fetch harness. Проверить T1…T4, повторный проход после ручного снятия; D1 00:00/12:00/23:59, D2 пусто/12:00 с неизвестностью, D3 пусто/12:6/текст места без ID/изменённый draft при карте. Каждый D — с обоими возвратами; сравнивать raw поля, выбранный ID и название.
2. Реализовать переход без document reload, form submit и storage. Ссылка работает при пустых/ошибочных полях и не переключает checkbox. Повторный возврат после закрытия — no-op. Утверждённый текст покрывает C1…C8; API intent сохраняет ровно birth_date/birth_time/place_id.
3. Нулевой прирост POST при открытии и возвратах дополнить реальным явным submit через тот же mounted UI: без отметки отказ, после ручной отметки и после «Согласен» ровно один POST. Не заменять предмет проверки моками.
4. Расширить DOM fixture и проверку статического текста в test_ui_delivery.py, включая installed wheel. Новый JS-модуль и новые маршруты не нужны. Существующие MIME/cache/no-business-events проверки сохраняются.
5. Упрости общий обработчик и видимость; проверь точечный diff, убери дубли, сохрани публичные тесты; listeners снять при dispose. Не перестраивать renderer или session.
