Статус «—» означает отсутствие оформления по новому процессу, не новый статус долга. Опись не отменяет исходные решения / ADR и не разрешает новые исключения для gates. Сроки, назначения и приоритеты не выдумываются. Предложения без решения вынесены отдельно.

Запланированные CI, Chart Renderer, чат / интерпретация, отдельный CLI application-path и расширение request events на unmatched routes не зарегистрированы как техдолг только потому, что ещё не реализованы.
