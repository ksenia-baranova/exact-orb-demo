# Требования отдельных изменений

Для каждого change создаётся папка `<change-id>/` с требованиями `requirements.md`, сценариями `scenarios.md` и
аналитическими findings/handoff в `analysis.md`. Создавай папку для реального change и используй его единый идентификатор.

- Формат требований — `DELTA` или `FULL`; выбор и исходный baseline записываются в документе.
- Формы документов — [шаблоны Analyst](../../development_approach/artifacts/functional-analyst.md).
- Правила размещения, переноса и ownership — [правила требований](../README.md).

После интеграции папка сохраняет историю изменения и ссылки на чистовую редакцию. Следующий change берёт baseline
из `current/` либо из явно зафиксированных прежних нормативных путей, пока соответствующие документы не перенесены.
