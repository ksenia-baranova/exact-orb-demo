# Исторические требования отдельных изменений

Этот каталог сохраняет опубликованные пакеты прежних change по исходным путям. Он не является местом создания требований нового change.

Для новых change используется `docs/project_management/change_plans/<change-id>/`: manager_artifact.md и индексы участвующих ролей и подпапки ролей. Требования / сценарии — в `analyst/requirements.md` и `analyst/scenarios.md`, findings — в `analyst/findings.md`, handoff — в `analyst_artifact.md`, карта переноса — в `analyst/transfer_map.md`.

Форматы DELTA / FULL, исходный baseline, approvals и перенос после приёмки, до merge определены в [правилах требований](../README.md). Следующий change использует актуальный нормативный baseline, а не повторно применяет историческую дельту. Прежние материалы мигрируют только отдельной согласованной задачей; опубликованные ссылки и source evidence сохраняются.
