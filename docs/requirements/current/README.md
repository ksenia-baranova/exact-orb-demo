# Чистовые требования

Здесь размещается полный действующий текст требований по областям и компонентам после подготовки переноса принятой
дельты или полной спецификации. На `main` это общий baseline для последующих change.

Порядок переноса и переход существующих документов определён в [правилах требований](../README.md).
В чистовом документе сохраняются ID требований и сценариев, ссылки на ADR и диаграммы, а также change ID и источник
принятой редакции. Для чтения действующего контракта не требуется восстанавливать историю дельт.

До явного переноса существующего документа используется его прежний нормативный путь, зафиксированный в baseline change.
Наличие этой папки само по себе не означает переноса ранее созданных требований.

Подготовка новой чистовой редакции выполняется в change после финальных approvals и решения Owner, до финального merge. Tester отдельно сверяет перенос; общий main-baseline изменяется только после интеграции. DELTA и исходные findings остаются в папке change как история.
