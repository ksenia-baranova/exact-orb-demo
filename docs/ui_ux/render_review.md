# Разбор рендеров

Дата: 2026-09-25. Объект: пять рендеров в `renders/`. Р1–Р4 — исходные PNG;
Р5 экспортирован из нового `web-prototype.html`, заменив отсутствовавший PNG.

Рендеры сгенерированы как визуальное направление. В них есть ошибки предметной
модели, элементы без действия и обещания, которые продукт пока не выполняет.
Этот список — причина правила из `README.md`: из рендеров берутся только
композиция, палитра и ритм.

## Р1 — ввод данных

| Что на рендере | Проблема | Как в требованиях |
|---|---|---|
| Галочка «Я согласен(а) с обработкой персональных данных» отмечена | Заранее отмеченная галочка не является согласием (ст. 9 152-ФЗ, разъяснения EDPB по GDPR) | Снята по умолчанию; текст и необходимость согласия утверждаются до публикации |
| «Ваши данные в безопасности», «Не передаём данные третьим лицам» | Не подтверждено: интерпретацию будет делать внешний LLM-провайдер, PII в DEBUG-журнале — принятый блокер публичного развёртывания | Не показывать до подтверждения |
| Порядок полей: дата, время, место, имя | Расходится с требованиями | Дата, место, время, имя |
| Поле «Имя» | `POST /charts/natal` отклоняет лишние поля | Открытое решение (`decisions.md`, №5) |
| Плашка «DEMO v0.9 — не первая версия» | Непонятно, что означает для пользователя | Не переносить |

## Р2 — карта готова

| Что на рендере | Проблема |
|---|---|
| Солнце в Деве в IX доме при ASC в Раке | Геометрически невозможно: при ASC около 17° Рака Дева попадает во II–III дома, а не в IX |
| Слева у ASC нарисован Стрелец | Не согласовано с ASC в Раке |
| На круге нет Рака и Козерога | Знаков должно быть двенадцать |
| Номера домов: «3» дважды, «1.» у ASC | Ошибка разметки |
| Луна в Овне нарисована в секторе Девы | Положение на круге не совпадает с подписью |
| Линии аспектов сходятся в центр | Аспекты — хорды между позициями планет на внутреннем кольце |
| Навигация «Транзиты / Соляр / Лунар / Совместимость / Библиотека» | Функций нет; не показывать в готовом интерфейсе |
| Цитата К. Г. Юнга | Декор, не несёт функции; решать отдельно |

## Р3 — справочник символов

| Что на рендере | Проблема |
|---|---|
| 16 точек, включая Хирон, Лилит, Селену, Парс Фортуны | Набор должен совпадать с точками, которые реально отдаёт движок (ADR-0029) |

| Подписи стихий («Импульс · воля · действие») | Это интерпретационный текст, а не справочные данные |

## Р5 — подробная карта

Текущий Р5 получен из экрана подробной карты в интерактивном прототипе. В нём
точные аспекты обозначены категорией `exact`, блок стихий показывает отсутствие
утверждённой методики, а разделы расположены последовательно. Замечания из
приложенного текста про порог «орбис < 1°», проценты стихий, пять вкладок и
кнопки скачивания относились к прежнему, не приложенному Р5 и к текущему PNG
не применяются.

Числа карты в прототипе заданы как демонстрационная фикстура. Геометрию и
подписи необходимо сверять с реальным результатом движка при реализации.

## Общее для всех рендеров

- Все значения планет и домов — демо-данные, а не результат движка.
- Ни один рендер не показывает состояния без времени рождения, загрузки, ошибки,
  устаревшей или недоступной карты.
- Мобильных рендеров нет: мобильные макеты сделаны отдельно, см. `mobile/`.
